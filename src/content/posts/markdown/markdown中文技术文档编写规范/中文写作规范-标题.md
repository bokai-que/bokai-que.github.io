# 2.1-标题

## 层级

标题分为四级。

- 一级标题：文章的标题
- 二级标题：文章主要部分的大标题
- 三级标题：二级标题下面一级的小标题
- 四级标题：三级标题下面某一方面的小标题

## 原则

- 一级标题下，不能直接出现三级标题。
- 标题要避免孤立编号（即同级标题只有一个）。
- 下级标题不重复上一级标题的内容。
- 谨慎使用四级标题，尽量避免出现，保持层级的简单和防止出现过于复杂的章节。如果三级标题下有并列性的内容，建议只使用项目列表（Item list）。
